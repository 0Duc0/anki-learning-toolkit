# Card Stage Shifter

The last choices made in the Stage Shifter dialog are saved here automatically.
Use `Tools` → `Learning Toolkit` → `Card Organization` →
`Card Stage Shifter…` for the guided settings and final move preview.

The default cap is 100 cards per source stage. Zero means all matching cards or
notes and should only be chosen deliberately. New cards are the only default
state; suspension is never removed automatically.

`even` (true/false) and `even_notes` (default 20) remember the Even-mode choice:
refill every stage to `even_notes` notes instead of using the per-stage cap.
