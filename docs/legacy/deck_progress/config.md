# Deck Progress

Use the **Config** button for the graphical settings window, or open
**Tools → Learning Toolkit → Deck Progress…**.

Add multiple named counters. For each counter, choose one or more decks, whether
to include their subdecks, cards or words (Anki notes), suspended cards, and an
optional total. **Only a. stages within this selection** can restrict a parent
language/category deck to Stage Shifter's a. decks.

Only cards with Anki answer count `reps > 0` count as studied. Being placed in a.
alone does not qualify. Notes count once when any selected card was answered.
Counters are independent, local to this computer, and saved per profile.

This add-on displays counts only. It does not move or change cards.
