# Study Session Clock

Use `Tools` → `Learning Toolkit` → `Study Clock` → `Settings…` to choose
which counters are visible, the focused-timer inactivity limit, and the default
history range.

- **Elapsed** is the session stopwatch and includes breaks by default.
- **Focused** counts active review-screen time and pauses after inactivity.
- **Logged today** is capped answer time stored in Anki's review log, including
  earlier sessions in the current Anki day.
- **Last** shows Anki's capped time for the latest answer.
- **Avg** shows the average since the current stopwatch session began or was
  reset. Last and Avg appear only in the review screen and can be switched on
  or off independently.

Click the status-bar clock to see the per-deck dashboard.
